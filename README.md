# Machine Learning Lab – Practical 9

## 📌 Overview
This repository contains the implementation of Machine Learning Lab Practical 9 using Python and Jupyter Notebook.

The practical focuses on **Clustering Techniques and Customer Segmentation** using the Wholesale Customers dataset.

## 🎯 Objectives
- Perform exploratory data analysis (EDA).
- Understand and preprocess customer data.
- Apply clustering algorithms.
- Visualize customer groups.
- Evaluate clustering performance using different metrics.

## 🛠️ Technologies Used
- Python
- Jupyter Notebook
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- SciPy

## 📊 Dataset
**Wholesale Customers Dataset**

The dataset contains customer spending information across different product categories:
- Fresh
- Milk
- Grocery
- Frozen
- Detergents_Paper
- Delicassen

It also includes Channel and Region information.

## 🧠 Algorithms and Techniques
- K-Means Clustering
- Agglomerative Clustering
- Principal Component Analysis (PCA)
- Hierarchical Clustering
- Dendrogram Visualization

## 📈 Evaluation Metrics
- Silhouette Score
- Davies-Bouldin Score
- Calinski-Harabasz Score
